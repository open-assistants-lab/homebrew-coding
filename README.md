# OpenAssistants Lab — Homebrew Coding

Public Homebrew tap for experimental coding tools.

## Etti status

Etti v0.1.0 packaging is in preparation. **No Etti formula or installable release has been published yet.**

The intended command, once a verified binary and formula are published, is:

```sh
brew install open-assistants-lab/coding/etti
```

This repository will hold Homebrew formulas and verified binary release artifacts. The tap name is `open-assistants-lab/coding`; the formula will be `Formula/etti.rb`.

Public downloads will not require GitHub credentials. Any Ollama Cloud credential is configured locally and must never be included in this repository, formulas or release artifacts.

Initial target: Apple Silicon macOS 14 or later, subject to completed compatibility testing. The release is experimental; signing, Keychain setup and clean-Mac verification must be documented before installation is advertised as ready.
